# Sadeem Energy 

## Sustainable & Nuclear Solutions Enterprise Portal

This repository contains the official frontend web application for **Sadeem Energy**, a UAE-born utility titan committed to engineering a sustainable, smart-managed energy future for generations to come. 

### Technology Stack
* **Framework:** React 18 / Vite
* **Styling:** Tailwind CSS + Framer Motion (for dynamic interactive animations)
* **Icons:** Lucide React
* **Routing:** React Router v6

### Key Features
* **Bilingual Support:** Full English and Arabic (RTL) localization context architecture.
* **Premium Enterprise Design:** High-impact "bento-box" grid layouts, glassmorphism elements, and cinematic parallax scrolling.
* **Strategic Integration:** Direct UI alignments with the UAE Energy Strategy 2050, D33 Agenda, and COP28 targets.

### Local Development
To run this application locally:

```bash
npm install
npm run dev
```

Navigate to `http://localhost:8080` in your browser.
